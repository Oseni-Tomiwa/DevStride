# DevStride Product Requirements

## Product statement
DevStride is a personalized AI software-engineering mentor and communication
coach for developers preparing to learn, build, interview, and participate
confidently in professional engineering conversations.

## Primary users
- junior software engineers;
- self-taught developers;
- bootcamp graduates;
- computer-science students;
- developers preparing for interviews;
- developers who need technical communication practice.

## Core outcomes
Users should be able to:
- understand technical concepts at their current level;
- practise technical and behavioral interviews;
- rehearse workplace communication;
- receive structured, measurable feedback;
- track recurring weaknesses and improvement;
- build real projects with guided support.

## MVP
- authentication and onboarding;
- persistent streamed chat;
- Mentor Mode;
- technical and behavioral interviews;
- structured scoring and reports;
- three workplace simulations;
- user-controlled memory;
- simple progress dashboard.

## Deferred
- voice;
- RAG;
- GitHub ingestion;
- code execution;
- multiple LLM providers;
- autonomous agents;
- microservices;
- billing and gamification.

## MVP completion flow
A user can register, complete onboarding, start a persistent streamed
conversation, finish a mock interview, receive a structured report, and return
later to find approved goals and weak areas remembered.
